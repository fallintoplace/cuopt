# Security Policy

## Reporting a Vulnerability

NVIDIA welcomes reports of suspected security vulnerabilities in cuOpt. Please **do not** open a public GitHub issue.

Submit reports through the [NVIDIA Product Security](https://www.nvidia.com/en-us/security/) page, or email [psirt@nvidia.com](mailto:psirt@nvidia.com).

Include, when possible:

- A description of the vulnerability and its impact.
- Steps to reproduce, including affected version and platform.
- Any proof-of-concept material.

Encrypt sensitive content with the [NVIDIA PSIRT PGP key](https://www.nvidia.com/en-us/security/contact/).

## Supported Versions

Security fixes are applied to the latest release on `main` and the most recent `release/*` branch. See the project's release schedule for what is currently supported.

## Disclosure

NVIDIA follows coordinated disclosure with reporters. We will acknowledge your report, investigate, and keep you informed of progress toward a fix and public disclosure.
